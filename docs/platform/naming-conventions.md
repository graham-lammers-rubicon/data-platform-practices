# Naming Conventions

> **Status: stub.** Scope is agreed; rules are not yet written. Not normative until this notice is removed.

Defines naming standards for every named resource on the platform. Nothing is named ad hoc; examples and templates elsewhere in this repo must follow these conventions.

## Scope (planned)

- Unity Catalog: catalogs (`<env>_catalog`), schemas (medallion layers), tables (see [Medallion data practices](../practices/medallion-data-practices.md) for layer naming rules)
- Jobs, pipelines, and bundles
- Azure resources: resource groups, storage accounts, key vaults, workspaces
- Service principals and groups
- Tags and metadata conventions for cost attribution and ownership
