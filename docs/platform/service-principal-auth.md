# Service Principal Authentication

> **Status: stub.** Scope is agreed; rules are not yet written. Not normative until this notice is removed.

Defines service principal authentication patterns for pipelines, jobs, Databricks Apps, and external integrations. Human identities never run production workloads.

## Scope (planned)

- Service principal types and when to use each
- One principal per pipeline/domain with least-privilege grants per the [access model](../governance/access-model.md)
- Credential management and rotation (see [Secrets and credentials](secrets-and-credentials.md))
- Auth patterns for Databricks Apps and external callers
