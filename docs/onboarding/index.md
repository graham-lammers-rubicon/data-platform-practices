# Onboarding

Role-based entry paths for new team members. Each path gives a reading order through the practices, platform, and governance docs, a first-week checklist, and the rules that role is held to.

## Paths

- [Data Engineer](data-engineer.md) - builds and operates Bronze/Silver/Gold pipelines
- [BI Analyst](bi-analyst.md) - turns governed Gold data into decision-grade outputs
- [Platform Engineer](platform-engineer.md) - owns Azure and Databricks infrastructure, identity, and deployment

If your role spans paths, start with the closest one and read the others' rule sections.
