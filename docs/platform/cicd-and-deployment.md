# CI/CD and Deployment

> **Status: stub.** Scope is agreed; rules are not yet written. Not normative until this notice is removed.

Defines how code and platform assets move from a developer branch to production. Everything deployable (jobs, pipelines, dashboards) is declared in bundles and deployed by automation, not by hand.

## Scope (planned)

- Repo and branching standard for platform code
- Databricks Asset Bundles as the deployment unit; one bundle layout standard
- CI checks: validation, tests, spec acceptance criteria (see [Spec-driven development](../practices/spec-driven-development.md))
- Promotion through environments (see [Environments](environments.md)); who approves what
- Deployment identity: service principals only (see [Service principal authentication](service-principal-auth.md))
- Rollback and hotfix procedure
